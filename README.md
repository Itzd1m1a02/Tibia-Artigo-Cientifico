# Análise Estatística de Imagens Termográficas para Detecção de Infecções e Doenças

Este repositório contém o código em MATLAB e o fluxo de dados utilizado no artigo científico focado no processamento e análise estatística de dados térmicos para suporte ao diagnóstico de processos infecciosos/patológicos.

---

## 📌 Visão Geral do Projeto

A termografia infravermelha é uma técnica não invasiva que permite mapear a distribuição de temperatura na superfície analisada. O objetivo principal deste trabalho é aplicar métodos de **análise estatística sobre imagens termográficas** para identificar padrões térmicos anômalos e verificar a presença ou ausência de infecções e patologias.

**Destaques da Metodologia:**
- Extração de métricas térmicas das regiões de interesse (ROI).
- Análise estatística descritiva e inferencial das variações de temperatura.
- Classificação/avaliação do padrão térmico para apoio à tomada de decisão clínica ou diagnóstico.

---
